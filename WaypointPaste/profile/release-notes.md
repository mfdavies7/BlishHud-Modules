## 1.0.0

First release.

- **Whisper a waypoint to yourself:** press the Paste Waypoint Hotkey or right-click the icon. Its chat link shows up in chat, ready to click or share.
- **Pick the waypoint:** paste its chat code into Waypoint Chat Code. A waypoint, point of interest or vista code you've just copied is used instead.
- **Auto-Click Chat Link:** clicks the link for you once the whisper is sent. Use Set Click Position Hotkey to set where it clicks.
- **Chat stays tidy:** Switch to /s After Whisper stops your next message going to yourself. Unsent text is left alone unless Overwrite Unsent Chat Text is on.
